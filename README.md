# Frågesport

Ett poängbräde för frågesport i webbläsaren. Kategorierna ligger som kolumner och varje ruta visar hur många poäng frågan är värd (100–500, svårare fråga ger fler poäng).

- Klicka på en ruta för att visa frågan, och sedan på "Visa svar".
- Lägg till personer eller lag i poängställningen längst ner. Plus och minus ger eller drar av poängen för den valda frågan.
- Spelade rutor gråas ut. "Nytt spel" återställer brädet och nollar poängen.
- Allt sparas i webbläsaren, så ställningen finns kvar om sidan laddas om.

Frågorna ligger i `CATS` i `index.html`.
